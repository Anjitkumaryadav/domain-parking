# OnlinePayment.in — Domain For Sale Landing Page

A clean, single-page React landing page to advertise the **OnlinePayment.in** domain for sale.

- **Price:** ₹25,00,000 (negotiable)
- **Enquiry email:** anjitaniket@gmail.com

## Tech

- React 18 + Vite

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (default http://localhost:5173).

## Build for production

```bash
npm run build
```

The static site is output to `dist/` — upload those files to any static host
(Netlify, Vercel, GitHub Pages, S3, or your domain registrar's hosting) and
point `onlinepayment.in` at it.

## Editing content

All copy lives in [`src/App.jsx`](src/App.jsx) — the `DOMAIN`, `EMAIL` and
`PRICE` constants at the top are the quickest things to change.
